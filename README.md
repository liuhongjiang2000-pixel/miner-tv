# 黄金矿工 TV 版 (MinerTV)

单机版黄金矿工，Android TV 遥控器适配。原创克隆（灵感来自经典 Flash 游戏），无任何素材取自原站。

## 玩法

- 钩子自动左右摆动，按 **确认键 / 方向下 / 空格 / 回车**（触屏点按同效）放出钩子
- 钩到矿石自动收回，越重的矿石收得越慢：大金块 500 分 > 中金 250 > 小金 100 > 钻石 600（快而轻）> 石头 40（重，基本赔时间）
- **问号袋**：随机奖励——加分 / 加时 / 大力
- 每关 **60 秒** 内达到目标分即过关，目标逐关提高（350 起，每关 +250）
- 主菜单显示历史最高分，破纪录自动存档

## 语音

中文语音播报（抓到矿石、过关、游戏结束），菜单可开关。电视上需装有 TTS 引擎（如 eSpeak）。

## 构建

GitHub Actions 推送即构建：`.github/workflows/build.yml` 解码 `app/miner.keystore.b64` 后 `gradle assembleDebug`，并把 APK 上传到 Release。
